Background span utilities

Add bg-span-container to the parent and a bg-span marker before sibling sections. It spans three sections by default; use a positive count such as bg-span-4 to change it.

Set each marker's image with a Tailwind class such as bg-[url('./background.svg')].

Top and bottom offsets default to 1/2; fractions such as 0, 1/4, and 3/4 are also supported.

Both offsets accept arbitrary percentages or lengths, such as bg-span-top-[37%] and bg-span-bottom-[32px].

Use responsive prefixes such as md:bg-span-top-1/2 to change offsets at a breakpoint.

Run npm run build after changing the HTML or utility CSS.
